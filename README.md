# 📊 Excel Student Performance Analysis Dashboard

## Overview
This project is an interactive Microsoft Excel dashboard designed to analyze student performance using formulas, PivotTables, PivotCharts, slicers, and conditional formatting.

## Features
- Student marks management
- Automatic Total and Percentage calculation
- Grade and Pass/Fail status calculation
- Conditional Formatting for performance analysis
- PivotTables for summarizing data
- PivotCharts for visualization
- Interactive Class Slicer (10A and 10B)
- Dashboard with multiple performance insights
- Printable Student Marksheet

## Dashboard Visualizations
- Student-wise Total Marks
- Grade Distribution
- Subject-wise Average Performance
- Student Performance Comparison

## Tools Used
- Microsoft Excel
- Excel Formulas (SUM, AVERAGE, IF)
- PivotTables
- PivotCharts
- Slicers
- Conditional Formatting
